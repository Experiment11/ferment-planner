# 🥬 Ferment Planner

A simple, friendly website for planning fermentation and pickling projects.
Pick what you want to ferment, get an exact salt-brine amount from the built-in
calculator, and build a shopping list with Amazon links.

## How to run it

No installation needed. Download the files and **double-click `index.html`** to
open it in your web browser.

## What it does

1. **Choose vegetables** — cabbage, cucumbers, carrots, radishes, and more.
2. **Or pickle something else** — eggs, jalapeños, red onion, mushrooms.
3. **Pick a salt and a container** — mason jar, clay crock, or airlock kit.
4. **Brine calculator** — choose a salt strength and method, enter your amount,
   and it tells you exactly how much salt to use.
5. **Shopping list** — every item you picked, each with an Amazon search link.

## Project structure

- `index.html` — the page structure
- `styles.css` — the look and feel
- `data.js` — the lists of items (with cartoon SVG drawings)
- `app.js` — the interactive logic

See [`ROADMAP.md`](ROADMAP.md) for what's planned next.

## Note on the images and Amazon links

Cartoon images are drawn in code as SVG, so they are original artwork with no
licensing concerns. Amazon links are plain product-search URLs for now; they can
be upgraded to Amazon Associates affiliate links later.
